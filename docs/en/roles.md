# Roles

AutoSpread roles are reusable responsibilities, not mandatory persistent agents. The Lead chooses the smallest set for the current constraint.

Core roles: Growth Lead; Product Auditor; Customer Researcher; Growth Engineer; SEO/GEO Operator; Monetization Operator; Content Strategist; Creative Producer; Channel Strategist; Channel Operator; Experiment Owner; Data Reviewer; Lifecycle Operator; Paid Acquisition.

See `../../skills/autospread/references/roles.md` for routing and deliverables. A single session may hold several roles; independent work may be delegated when the host makes that useful.
