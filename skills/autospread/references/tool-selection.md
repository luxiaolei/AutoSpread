# Tool selection

Choose the least fragile available capability.

| Need | First choice | Fallback |
| --- | --- | --- |
| Repository, issue, or pull request | Git or the official provider API | browser inspection |
| Product behavior or funnel data | connected analytics API | exported report |
| Search and external research | source-backed search tool | browser search with citations |
| Visual website or logged-in flow | approved browser session | record the access gap |
| Repeatable publishing | authorized channel API or CLI | prepared draft |
| Video or image asset | existing approved generator or renderer | script and shot list |

Do not infer access from an installed skill. Check the actual connection before
using a tool and record the limitation when it is unavailable.
