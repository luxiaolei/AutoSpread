# Delegation

Delegate only when the work is independent, the host supports it, and the
handoff is cheaper than doing it in the current session.

Every handoff states:

- objective and relevant product files;
- role method to apply;
- allowed tools and forbidden external actions;
- expected artifact and evidence standard;
- dependency, deadline, and failure condition.

The Lead checks returned work against the evidence standard. A queued request
is not a completed task, and a child session cannot be reported as successful
without an inspectable result.
