# 数据分析与复盘

## 先建立指标契约

计算前明确指标名称、业务含义、事件/公式、人群、分母、归因逻辑、周期/时区、事实来源和数据延迟。

## 校验

检查事件/Schema 变化、重复、缺失周期、机器人/内部流量、必要时的退款/取消、身份 Join、Campaign 参数，以及分析、支付和搜索来源之间的差异。重大冲突未解决前不能用于决策。

## 分析

- 区分量级变化、转化率变化和流量 Mix 变化；
- 只有有用且数据足够时才按渠道、Landing、Cohort、设备/地区分层；
- ID 允许时追踪曝光/点击 -> 合格访问 -> 注册 -> 激活 -> 付款 -> 留存的下游质量；
- 区分相关、前后变化和受控因果证据；
- 比较增长杠杆时包含成本和机会成本。

## 闭环

对照实验预先声明的主指标和护栏，给出计算、来源链接/查询、限制、因果置信度，以及继续/停止/回滚/放大/学习决定。`证据不足` 是合法结果。
