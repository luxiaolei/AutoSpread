# Analytics and review

Define the metric, population, period, denominator, and source before calculating.
Check tracking changes and data quality. Separate descriptive results from causal
claims, state uncertainty, and compare against the predeclared guardrails. Deliver
the calculation, evidence links, caveats, and a continue/stop/learn decision.
