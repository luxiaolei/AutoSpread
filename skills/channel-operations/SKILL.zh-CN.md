# 渠道运营

在 `channel-selection` 和内容批准之后使用。

## 动作前

确认渠道/账号、目标用户、素材版本、目标 URL、Campaign/UTM、审批/自主权状态、平台要求，以及当前工具能否核验结果。

## 工具路由

优先官方 API/MCP -> 官方 CLI -> SDK/代码 -> 已批准的 `ego-browser` UI -> 人工交接。浏览器用于缺乏可靠结构化接口的登录态 UI 工作，而不是绕过平台规则。

## 安全执行

- 平台支持时使用 idempotency/operation key；
- 同一账号无法安全并发写入时串行执行；
- 超时结果不明确时先查询外部状态，再决定是否重试；
- 保存帖子/视频/提交/排期的外部 ID 和 canonical URL；
- 明确区分草稿、已排期、已提交、已发布、被拒绝和状态未知；
- 社区渠道按社区和平台规范参与，不能伪装成自动化垃圾推广。

## 核验

只有外部系统真实显示目标状态才算完成。记录时间、账号、外部 ID/URL、素材 ID、Campaign/落地页和核验方式。
