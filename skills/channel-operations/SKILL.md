# Channel operations

Confirm the channel, audience, content version, destination, and approval
status. Prefer the authorized API or CLI for repeatable actions. Before a write,
record the intended operation; after it, query external state and keep the post
or schedule identifier. If access is missing, return a publish-ready draft and
say exactly what remains.
