# Content and Video Production

Use `content-strategy` first when the topic or audience is unclear.

## Production method

1. Start from a validated problem, content brief, target audience, destination page, and desired action.
2. Select the format because it demonstrates the insight well: text, screenshot, diagram, real product demo, tutorial, short video, long video, or another asset.
3. For software, prefer real product footage and reproducible demonstrations when the product itself is the proof. Use generated visuals only when they add value and remain truthful.
4. Build a small variation set around meaningful hypotheses such as hook, pain framing, result framing, comparison, or length. Do not mass-produce near duplicates without a test reason.
5. Keep claims traceable to product facts, customer evidence, or cited research. Flag placeholders and unsupported claims.
6. Adapt dimensions, pacing, title, caption, subtitle, thumbnail, CTA, and metadata to the chosen channel after the core message is sound.
7. Run factual, brand, accessibility, copyright/licensing, and destination-link checks before handoff.

A generated asset is a draft until the required checks pass. Publishing belongs to `channel-operations`.
