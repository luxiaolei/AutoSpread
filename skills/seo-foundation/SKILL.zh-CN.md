# SEO 基础

## 调研

1. 明确优先用户、商业/信息意图、现有落地页和已知查询。
2. 检查 robots、sitemap、canonical、重定向、状态码、渲染后的文本、metadata、内链、重复/筛选 URL 和可索引性。
3. 有条件时优先读取 Search Console 等第一方数据，区分需求、曝光、排名、CTR、落地页行为和转化。
4. 只有影响用户体验或发现能力时才优化性能，不为了单一跑分而优化。

## 实施与调优

- 重要页面有清晰主意图，同时覆盖有价值的相关子问题；
- 用导航和内链提升可发现性；
- 重要事实和答案保留在可索引文本中；
- 结构化数据必须和可见内容一致；
- 只有能增加独立用户价值时才新建页面，不批量制造关键词变体；
- 增长改动中保护 canonical 和 redirect 行为。

## 核验

重新抓取受影响 URL，检查真实渲染页面，必要时验证 Schema，并定义 Search Console 观察窗口。不得承诺索引或排名。
