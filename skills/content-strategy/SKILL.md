# Content Strategy

Start with a problem or decision the audience actually has, not a platform posting quota.

## Method

1. Read product context, customer research, search/GEO gaps, objections, support questions, and recent performance.
2. Build a small set of content pillars tied to real jobs-to-be-done, buying questions, or repeated problems.
3. For each pillar, define the useful insight, evidence source, target audience, desired next action, and candidate distribution surfaces.
4. Create a core asset when appropriate, then derive channel-native variants rather than inventing unrelated posts per platform.
5. Balance acquisition content with proof, education, comparison, implementation, product demonstration, and customer evidence.
6. Reject topics that are popular but attract the wrong audience unless they serve another explicit objective.
7. Feed high-performing questions back into website, docs, GEO pages, onboarding, and product messaging.

## Output

Return priority themes, evidence, audience, asset map, channel hypotheses, reuse plan, CTA/landing destination, and measurement plan.
