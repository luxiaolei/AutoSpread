# E-commerce SEO

只有站点是商店、Catalog、Marketplace 或存在可索引电商产品页时使用。

## 产品和分类完整性

1. 检查 Product/Category 意图、真正有价值的独立描述、Specs、Availability、Price/Currency、Variant 关系、Review/UGC、图片、Shipping/Return 和商家身份。
2. 用页面可见事实和 Billing/Catalog 数据源验证 Product/Offer/Variant Schema，绝不能输出过期价格或库存。
3. 明确 Canonical/Variant/Faceted Navigation 规则，避免 Filter、Sort、Tracking 参数和缺货状态制造失控重复索引。
4. 用 Breadcrumb 和 Related/Category Link 连接产品与商业站点架构。
5. 图片、Schema、Sitemap 覆盖交给 `seo-site-integrity`。

## Merchant 和 Marketplace

有授权数据时，比较 Organic/Search 与 Merchant/Shopping 可见度、Seller/Price Context 和 Listing Quality。Provider 数据/API 成本与自然 SEO 分开处理，付费 API 或广告变更前遵守预算/审批策略。

## 搜索体验

Category/Product/Query 页面类型错位交给 `search-experience`；Product Page/Cart/Checkout 摩擦交给 `conversion-optimization`。不能把更多自然流量导入一个破损或误导的购买体验。

## 输出

给出 Catalog/索引风险、Product/Category 机会、Schema/Merchant 不一致、图片/内容缺口、商业 Query 机会，以及连接到合格 Product View、Add-to-cart、Purchase/Revenue、Margin 或约定业务指标的实验。
