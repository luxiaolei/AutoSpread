# Lifecycle operations

Define the segment by behavior, not a vague persona. Identify the missing event
or user value, then draft one message and a measurement rule. Respect consent,
frequency, and channel limits. Do not send or create an automation without the
user's authorization; return a reviewed draft and test plan when approval is absent.
