# Project audit

Inspect the product, public pages, available analytics, and recent work log.
Separate observed facts from assumptions. Check the main path from landing page
to activation, note broken or unmeasured steps, and rank findings by evidence,
impact, and effort. Deliver a short audit with source links, unknowns, and the
smallest safe next step. Do not change production while auditing.
